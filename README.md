# DNC–VSTEP

Website Trung tâm Chuẩn đầu ra — Trường Đại học Nam Cần Thơ (Next.js App Router).

## Getting Started

Chỉ dùng **pnpm**:

```bash
pnpm install
pnpm dev
```

Mở [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
pnpm lint
pnpm typecheck
pnpm format:check
pnpm build
```

Quy ước component / styling: xem `AGENTS.md`.
